# NEER / NeerBand

Safety-focused system exploring emergency assistance, location tracking, and real-time safety events.

## Overview

NEER is an IoT-inspired emergency safety project developed to address time-critical safety scenarios. The system captures real-time location coordinates during an emergency trigger and pushes timestamped event data to a cloud database for live monitoring.

## Key Features

- **One-Click SOS Alert Trigger**: Instant panic-friendly emergency activation.
- **Real-Time Location Capture**: Captures GPS location coordinates upon activation.
- **Cloud-Backed Event Tracking**: Pushes emergency alerts and timestamps to Firebase Realtime Database.
- **Live Monitoring View**: Guardian-accessible interface displaying emergency alert status.

## Tech Stack

- **Languages**: JavaScript, Java, HTML5, CSS3
- **Database & Cloud**: Google Firebase Realtime Database
- **Hardware Concept**: ESP32 / GPS module integration
